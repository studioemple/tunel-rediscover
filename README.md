# Rediscover tunel – raspored panela

Interaktivni tlocrt tunela za Rentlio Rediscover 2026: 20 panela na zidovima (pregled grafike na hover/dodir), naljepnice godina na podu i prikaz dimenzija tunela.

Statična stranica bez build koraka: `index.html` + `panels/*.jpg`.

## Objava na Vercelu
1. Na vercel.com → **Add New… → Project** → uvezite ovaj GitHub repozitorij.
2. Framework preset: **Other**, bez build naredbe, output directory: `.` (korijen).
3. **Deploy**.
